# 🚀 Asterisk PBX Web GUI & CRM Integration Suite

**Asterisk PBX Web GUI** — комплексная программная АТС на базе Asterisk 20+ и Flask, разработанная специально для микрокомпьютеров (Raspberry Pi 3B/4/5, Orange Pi) и серверов Debian/Ubuntu. Решение объединяет управление SIP-абонентами, динамическую маршрутизацию, многоуровневый интерактивный IVR-конструктор, стереозапись разговоров и автоматическую сквозную интеграцию с **amoCRM (API v4)**, **Telegram** и внешними облачными хранилищами (**amoCRM Drive, Google Drive, FTP/HTTP Web-Storage**).

---

## 🌟 Ключевые возможности

### 1. 📞 Телефония и маршрутизация (Asterisk 20+)
* **Поддержка GSM-модемов (chan_dongle):** входящие и исходящие звонки через 3G/4G USB-модемы (Huawei E1550, E173 и др.) и голосовые пулы.
* **SIP-транки и провайдеры:** подключение внешних операторов и шлюзов с поддержкой Failover (резервирования линий).
* **Стереозапись разговоров (2 канала):** двухканальная запись в формате PCM 8000Hz (L — оператор, R — клиент) со стартом записи строго при поднятии трубки `Dial(...,U(sub-record-start))`.
* **Международный номерной план:** полная поддержка номеров ОАЭ/Дубая (`+971`, `05X...`, `04...`), РФ (`+7`, `8`), СНГ и Европы с автоматической нормализацией номеров.
* **Внутренняя связь:** поддержка 3- и 4-значных номеров, параллельный вызов групп операторов (`ALL`), эхо-тест (`777`).

### 2. 🎛 Интерактивный конструктор IVR
* **Визуальное дерево голосового меню:** настройка узлов меню, загрузка и воспроизведение голосовых приветствий WAV.
* **Ветвление по DTMF-клавишам:** перевод звонка на других операторов, группы или дочерние подуровни IVR.
* **Управление рабочими часами (Work Hours):** автоматическое перенаправление ночных звонков и вызовов в выходные дни на специальное аудиосообщение (`ivr-offhours`).
* **Тестирование меню (Debug Mode):** вызов с софтфона на номер `888` для проверки IVR без реального звонка на GSM-линию.

### 3. 💼 Полная интеграция с amoCRM (API v4)
* **Автоматическое создание сущностей:** мгновенный поиск контакта по нормализованному номеру или создание нового контакта и сделки (Lead) в выбранной воронке и этапе.
* **amoCRM Drive Upload:** прямая загрузка аудиофайлов звонка во встроенное защищенное хранилище amoCRM Drive с получением нативной ссылки на воспроизведение.
* **Карточка звонка со встроенным веб-плеером:** фиксация события `POST /api/v4/calls` с длительностью, статусом (ANSWERED / NO ANSWER / BUSY), ответственным сотрудником и встроенным аудиоплеером прямо в таймлайне сделки.
* **Live Auto-Sync Stream:** отображение журнала обмена с amoCRM в веб-интерфейсе в режиме реального времени.

### 4. 📢 Telegram Уведомления и Умный Прокси
* **Многопользовательская рассылка:** отправка карточек звонков нескольким пользователям или группам (список Chat ID через запятую).
* **Поддержка реверс-прокси и обход блокировок:** автоматическая проверка доступности `api.telegram.org` с переключением на защищенный прокси-сервер (`telegram.dentaldate.ae` / `185.243.76.230`) при блокировках провайдера.
* **Прямые ссылки на запись:** карточка уведомления содержит кликабельную ссылку на прослушивание звонка в amoCRM Drive / Web-хостинге.
* **Тестирование подключения в UI:** встроенный инструмент проверки отправки тестового сообщения с детальным журналом ответов API.

### 5. 🗄 Хранилища и выгрузка записей (FTP / Web / Google Drive)
* **Выгрузка на FTP / Web-хост:** автоматическая отправка `.wav` записей на FTP-сервер с генерацией публичной HTTP/HTTPS ссылки для CRM и Telegram.
* **Тестирование FTP в UI:** проверка учетных данных FTP (CONNECT, LOGIN, PWD, PASV, QUIT) в 1 клик с выводом полного лога соединения.
* **Резервное копирование в Google Drive:** фоновая загрузка в папку архива Google Диска.
* **Auto-Discovery записей:** интеллектуальный поиск аудиозаписи в `/var/spool/asterisk/monitor/` при любых нестандартных сценариях сброса вызова.

### 6. ⚡ Отказоустойчивость и архитектура
* **Asterisk 20 Post-Call Hangup Handler:** использование `CHANNEL(hangup_handler_push)=sub-post-call-sync` гарантирует 100% запуск синхронизации в ту же секунду, когда опускается трубка.
* **Атомарная дедупликация (`acquire_call_lock`):** блокировка на уровне файловых дескрипторов исключает повторную обработку и дублирование сообщений при параллельном звонке на группу операторов.
* **Сохранение конфигурации:** файл `/opt/integrations_config.json`, SIP-аккаунты и база данных защищены от перезаписи при обновлениях.

## 🚀 Установка (на чистую систему)

Для установки на Raspberry Pi OS, Debian 11/12 или Ubuntu выполните команду:
```bash
sudo apt-get update && sudo apt-get install -y git && sudo rm -rf /opt/asterisk-gui && sudo git clone https://github.com/apavlishev/asterisk-ui-vps.git /opt/asterisk-gui && cd /opt/asterisk-gui && sudo ./install.sh
```

Панель управления будет доступна по адресу: `http://<IP_АДРЕС_АТС>:8080`

---

## 🔄 Способы обновления системы

### Способ 1: Через веб-интерфейс (в 1 клик)
1. Откройте панель управления (`http://<ip-адрес>:8080`).
2. Перейдите во вкладку **«Обновление»**.
3. Нажмите кнопку **«🚀 Установить обновление»**.

---

### Способ 2: Через терминал / SSH
Если система уже развернута на сервере:
```bash
sudo bash /opt/asterisk-gui/updater.sh
```

## 📂 Структура проекта

* `app.py` — Flask Web GUI, REST API панели, генератор диалплана `extensions.conf` и PJSIP-конфигураций.
* `crm-yandex-uploader.py` — автономный обработчик постобработки звонков: нормализация, выгрузка на amoCRM Drive / Google Drive / FTP, фиксация звонков в CRM и отправка Telegram-уведомлений с дедупликацией.
* `tg-bot-daemon.py` — фоновый сервис мониторинга и сервисных оповещений.
* `migrate.py` / `migrations/` — подсистема версионирования и миграции структуры данных конфигураций.
* `version.json` — манифест текущей версии и список изменений.
* `install.sh` / `updater.sh` — скрипты первоначальной установки и безопасного OTA-обновления.
