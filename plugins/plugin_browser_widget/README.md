# Виджет-телефон для браузера (Browser Softphone Widget)

Расширение для Chrome / Edge / Opera / Firefox, которое работает как телефон
прямо в браузере — по аналогии с виджетом Mango Office.

## Возможности

- **Всплывающий телефон** на любой странице (клик по иконке расширения или
  окно-попап).
- **WebRTC-звонки** прямо из браузера через SIP-over-WSS: приём входящих,
  ответ, mute, DTMF.
- **Click-to-call** через API панели: АТС звонит на обычный телефон/софтфон
  оператора и соединяет с клиентом.
- **Распознавание номеров на странице** (в т.ч. в amoCRM/Bitrix24):
  подсветка и звонок в один клик.
- **Контекстное меню**: выделить номер → «Позвонить через АТС».

## Файлы

```
plugin_browser_widget/
├── manifest.json            # Манифест плагина для панели
├── settings.html            # Экран настроек и скачивания расширения
├── locales/                 # Локализация (10 языков)
└── extension/               # Исходники самого браузерного расширения
    ├── manifest.chrome.json # Манифест для Chrome/Edge (MV3)
    ├── manifest.firefox.json# Манифест для Firefox (MV2)
    ├── background.js        # Service worker: контекстное меню, попапы
    ├── content.js           # Детект номеров и click-to-call на странице
    ├── widget.html/.js/.css # Сам виджет-телефон
    ├── sip.js               # Загрузчик sip.js (ESM)
    └── icons/               # Иконки 16/48/128
```

## Установка

Скачайте архив на странице плагина в панели
(`/api/widget/download?target=chrome` или `?target=firefox`) и установите как
«распакованное расширение».

### Chrome / Edge / Opera
1. `chrome://extensions` → включить «Режим разработчика».
2. «Загрузить распакованное расширение» → выбрать папку из архива.

### Firefox
1. `about:debugging#/runtime/this-firefox`.
2. «Загрузить временное дополнение» → выбрать `manifest.json`.

## Настройка расширения

В попапе нажмите ⚙ и заполните:

| Поле | Значение |
|------|----------|
| Адрес АТС | `IP-панели:порт` (например `138.124.229.10:8888`) |
| API-ключ | токен из раздела «Вебхуки / API» |
| Внутренний номер | ваш SIP-номер (например `101`) |
| SIP-пароль | пароль софтфона (для WebRTC) |
| WSS-адрес | необязательно, обычно `wss://IP/ws` |

Кнопка **«Получить с АТС»** запрашивает конфигурацию у панели по API-ключу.

## API панели (используется виджетом)

| Метод | Путь | Назначение |
|-------|------|-----------|
| GET  | `/api/widget/ping` | Проверка доступности |
| GET  | `/api/widget/config?exten=101` | Адрес АТС, WSS-URL, SIP-пароль |
| POST | `/api/widget/call` | Click-to-call: `{operator, phone}` |
| GET  | `/api/widget/download?target=chrome\|firefox` | Скачать расширение |

Авторизация: заголовок `X-API-Key` (тот же токен, что и для вебхуков).

## Требования

- Для WebRTC на АТС должен быть поднят SIP-over-WSS (порт 443).
  Настройка выполняется в разделе **Веб-софтфон** панели («Настроить WebRTC»).
- Номеру оператора должен быть разрешён WebRTC (включён для софтфона).
