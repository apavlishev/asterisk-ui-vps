Настройки Telegram SIP Trunk

Авторизация клиентского аккаунта через MTProto (Telethon) для интеграции в ядро.

info Инструкция по настройке:

  1. Перейдите на официальный портал my.telegram.org.
  2. Авторизуйтесь по номеру телефона, который будет использоваться как SIP-транк.
  3. Перейдите в раздел API development tools и создайте приложение (App).
  4. Скопируйте App api_id и App api_hash и вставьте их в поля ниже.
  5. Введите номер телефона, запросите код и завершите авторизацию.

vpn_key Авторизация

settings_ethernet Маршрутизация
