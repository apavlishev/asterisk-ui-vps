info Инструкция по настройке транка

Для работы Telegram SIP Trunk необходимо авторизовать аккаунт (MTProto), собрать шлюз tg2sip-webrtc и настроить ядро Asterisk на прием звонков с локального шлюза.

Шаг 1: Авторизация Telegram
  1. Перейдите на my.telegram.org.
  2. Авторизуйтесь по номеру транка.
  3. Перейдите в API development tools.
  4. Скопируйте api_id и api_hash.
  5. Внесите их ниже, запросите код и войдите.
Шаг 2: Сборка и запуск шлюза

Нажмите «Установить / пересобрать» выше — панель соберёт шлюз tg2sip-webrtc из исходников в фоне.

Шлюз слушает строго на 127.0.0.1. Порт 5062 (или выбранный ниже) недоступен из интернета — PJSIP обращается к шлюзу внутри сервера, авторизация не требуется (identify по локальному IP).

Шаг 3: PJSIP (генерируется автоматически)

После включения транка и сохранения настроек панель сама добавляет endpoint в pjsip.conf и контекст from-telegram в диалплан. Блок ниже приведён для справки:

[telegram-trunk]
type=endpoint
transport=transport-udp
context=from-telegram
disallow=all
allow=opus,alaw,ulaw,slin16
aors=telegram-trunk

[telegram-trunk]
type=aor
contact=sip:127.0.0.1:5062

[telegram-trunk]
type=identify
endpoint=telegram-trunk
match=127.0.0.1

vpn_key Авторизация

settings_ethernet Маршрутизация

Через этот UDP-порт транзитный шлюз будет связываться с ядром Asterisk. PJSIP-эндпоинт добавляется автоматически.

Используется, если для Telegram не настроено отдельное IVR-меню. Индивидуальное меню настраивается в разделе IVR (маршрут «Telegram»).
